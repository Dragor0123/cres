# 012 — 계산량을 맞춘 대조군 (sup2)

R004 §5. +NaQ·+CRES arm은 스텝마다 에피소드 2개(지도 1 + pseudo 1)로 갱신하고, 지도 단독(sup)은 1개로 갱신한다. 갱신량 차이만으로 생기는 이득을 분리한다.

## 1. arm 정의

- `sup2_l<λ>`: 스텝마다 **지도 에피소드 2개**. 두 번째 에피소드는 첫 번째와 같은 방식(전역 `random`, 같은 base 클래스 풀)으로 **하나 더** 뽑는다. 손실 `L = L_sup(ep1) + λ·L_sup(ep2)`, λ ∈ {0.5, 1.0}. 003 백본의 `train_step(sup, pseudo, lam)`에 `pseudo` 자리에 두 번째 지도 에피소드를 넣는 것과 같다(코드 경로 공유, 레이블 규칙 §4 준수: 두 에피소드 모두 base 레이블만).
- 전역 `random` 소비가 sup과 달라지므로, 고정 valid·test 에피소드는 파일에서 읽는 규칙(R002) 덕분에 영향이 없다. 학습 중 에폭 내 valid·test 50개(모델 선택용이 아닌 로그)는 달라져도 된다. 모델 선택은 고정 valid 100개로 한다(R002 §5)는 점을 확인하고 보고서에 적는다.
