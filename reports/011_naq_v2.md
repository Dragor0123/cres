## 1. 무엇을 했는지

### 수정 (`baselines/naq/generator.py`, 커밋 `acbc922`)

1. **K-shot support 구성 = 원 NaQ.** refs/NaQ(`cfe5373`)를 다시 읽고 확정한 사실:
   - `task_generator.py:61`, `:98` — 비지도(`unsup`) 학습 에피소드는 `spt_to_sample = 1  # only 'UMTRA' style initial spt generation is considered.`로 **test K와 무관하게 way마다 support 1개**.
   - `task_generator.py:112-130` `spt_sampling` — `id_train`에서 `random.sample(id_train, n_way*k_shot)`(여기서 k_shot = 1), 무작위 pseudo-label.
   - `task_generator.py:133-155` `query_generation_NaQ` — support 노드 행의 유사도 상위 `to_gen`(= `q_query`)개가 query. 중복 제거 없음.
   - `arg.py:21-24`, `:74-77` — 학습 `k_shot` 기본 1("1 used"), 평가 `k_shot_test` 1/5, 학습 `q_query` 기본 10, 평가 `q_query_test` 8.
   - 따라서 v2: support = anchor 1개(K=1, 5 모두), query = anchor 목록 상위 Q개. 이 리포의 Q는 5(TEG 학습 설정)를 유지했다(원 NaQ 학습 q_query 10과 다름 — 결정 필요 2).
2. **에피소드 안 중복 금지.** anchor 5개를 먼저 뽑아(`rng.choice(|U|, 5, replace=False)`, 006과 같은 호출) 예약하고, way를 순서대로 채우며 이미 쓴 노드는 목록에서 건너뛴다. 목록이 바닥나면 그 anchor를 버리고 같은 rng(`rng.integers`)로 쓰지 않은 노드를 새 anchor로 뽑는다. 재추첨 횟수 기록.
3. 풀 U(base 제외), rng `22000+seed` 유지.
4. 유사도 목록 길이 9 → 50(`TOP_V2`). 캐시 `results/011/<ds>/naq_<kind>_seed<s>_top50.npy`(새로 생성), allpool은 `naq_feat_all_top50.npy`.
- 006 구성은 `NaQGeneratorV1`로 같은 파일에 남겼다(통계 비교용, 학습 경로에서 쓰지 않음).
