## 1. 무엇을 했는지

- `cres/core.py`: `RScorer`(r = C1(ψ), anchor 블록 × 풀 U 전체를 정확히 계산하는 `block`, 집합 내부 r 행렬 `within`), `greedy_core`, `stable_topk`.
  - 검증: dblp seed 0에서 `block` 값과 ψ 함수 + C1 직접 계산의 최대 절대 차 5.4e-7(무작위 쌍 2만 + 후보 목록 쌍), `within` 1.6e-6.
- `tools/gate2.py`: anchor = U의 모든 노드. U 안 r(a,·) 상위 30 후보 → 탐욕 core(m ∈ {6, 10}, τ_in ∈ {0.3, 0.5, 0.7}). B1 = s_H 상위 m−1, B2 = s_X 상위 m−1, B3 = r 상위 m−1(모두 U 전체에서, 동점은 노드 id 오름차순). τ 선택은 valid anchor, 판정은 test anchor.
- 레이블 사용: core·B1–B3 구성에는 쓰지 않음. 풀 U 결정(base 제외), valid/test anchor 구분, 순도·충돌 지표에만 사용.
- 명령: `CUDA_VISIBLE_DEVICES=<GPU-A> /venv/cres/bin/python tools/gate2.py --dataset <ds>` (seed 0,1,2). 로그 `results/005/logs/gate2_<ds>.log`. 데이터셋·seed당 4–7 s.
- 기록 `records/005_gate2/`: `summary_<ds>_seed<s>.json`(τ 표, 순도, 짝지은 차, 충돌), `verdict_<ds>.json`, `anchor_<ds>_seed<s>_m<m>.csv`(U anchor별 그룹·채택·core/B1/B2/B3 순도; 기각 anchor의 core 열은 의미 없음), `core_bank_<ds>_seed<s>_m<m>.json`(선택 τ에서 채택된 모든 U anchor의 core, 최대 1.27 MB).

## 4. 결정 필요

1. Electronics의 G2 통과는 B1(s_H)이 약한 데서 오는 차이가 대부분이다(core − B2 +0.1 ~ +1.0%p, core − B3 ≈ 0). 등록 기준대로 "통과"로 적었으며, 비교 기준(B1)을 무엇으로 볼지는 사용자 판단.
2. r의 방향(ψ(u, v)의 u가 첫 번째)과 탐욕 단계의 r(v, w) 방향을 P03 "구현 세부"에 Claude가 정해 적었다. 검토 필요.
